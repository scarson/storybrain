# Finding 08 — A model generated the lore, and it works end-to-end

Answers the user's directive: **generate facts with a model, not by hand.** The
staged LLM pipeline (canon seed → artifacts → validate/link) produced a coherent
sci-fi world that loads into the SQLite store, drives the Director, and whose
central mystery reconstructs. Code: `storybrain/generator/`. Reproduce:

```
bun storybrain/generator/check.ts          # validate the generated world
bun storybrain/generator/load.ts           # load + Director multi-tick + mystery
bun test storybrain/generator/schema.test.ts   # validator contract (6/6)
```

## What the model generated (themes, all present)

`world-scifi.json` — 34 nodes (6 artifacts, **2 distinct alien civ types**), 53
edges, a **5-fragment mystery chain**. Generated by an Opus-class subagent from
`prompt-canon.md` + `prompt-artifacts.md`; **validated first try**.

- **The Velt** — crystalline slow-life, one thought per century, cognition stored
  in stone (psychic power: *lithomancy*).
- **The Choir** — a bodiless psychic gestalt living in the planet's resonance
  (*resonant-sympathy*).
- **The mystery (resource exploitation gone terribly wrong):** the "ore" the Velt
  mined to quicken their slow minds was the dormant **nerve-tissue of a
  planet-spanning organism**. Every bore-shaft was an amputation; the world woke
  in pain, discharging a psychic standing-wave; the Choir threw its whole gestalt
  into singing it down; the planet learned their frequency and answered in their
  voices; the amplified wave raced the marrow-seams and **vitrified the Velt and
  dissolved the Choir in one instant**. The seams run under the human colony, and
  the marrow-shard still beats. Ordered `caused_by` chain:
  `the-marrow-was-alive → extraction-was-amputation → the-wound-sang →
  the-choir-tried-to-sing-it-down → the-resonance-cascade`.

This is exactly the requested palette — alien civs of different types, psychic
powers, ancient mystery, why-a-civilization-fell, resource exploitation gone
*terribly* wrong — and it's genuinely good sci-fi, generated, not authored.

## It loads and drives

- Loads cleanly into the SQLite ship schema (34 nodes, 53 edges).
- Catalog queries work on the generated world (e.g.
  `artifact_provenance(kaels-bore-codex)` → drops `velt-thought-in-stone`,
  `forged_by` velt-deepwright-kael; factions by tension: Choir 0.85, Velt 0.8,
  humans 0.4).
- **Mystery reconstruction:** revealing all fragments (a full artifact hunt) +
  following `caused_by` reconstructs the fall in order — caused_by chain connects
  all consecutive fragments (✓), full mystery reconstructable (✓).

## A real bug the GENERATED world surfaced (and the fix)

The first multi-tick run snowballed onto the highest-tension faction (the Choir),
resonance *climbing* 0.045 → 0.498, because the Director's own `involves` event
edges inflated that faction's inbound callback every tick it fired — a feedback
loop the tiny hand-seeded sim (finding 07) never exposed. **Fix (the finding-05
lesson again):** callback counts only **stake edges** (`rival_of`, `betrayed_by`,
`sought_by`, `owned_by`, `reveals`, …), never the Director's own bookkeeping.
After the fix the sequence diversifies:
`the-velt → discovery → the-choir → discovery → humans → the-velt` — 4 distinct
targets, no snowball. *Lesson: testing on a real generated world finds feedback
bugs hand-built demos hide.*

## Pipeline architecture (POC vs production)

- POC: the "model" is a Claude subagent (Agent tool) writing JSON; the
  deterministic `validateWorld` contract (6/6 tests) gatekeeps loadability +
  coherence (every edge → declared node; ≥3 facts/artifact; mystery fully covered
  by artifact `drops`).
- Production: swap the subagent for the Anthropic API with the SAME prompts —
  `claude-opus-4-8` for the canon seed (coherence-critical), `claude-haiku-4-5`
  for bulk artifacts (cheap). Prompts + schema + validator are the portable
  artifacts; nothing else changes.
